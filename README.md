# Chapter 12 - Animal Simulator

For this project, I first had updated the animal simulator that originally had foxes and rabbits. I then moved some of the code from the Fox and Rabbit classes into the Animal class. This includes things like the aging and breeding. This makes the code simpler and avoids repeating the same methods.

I also created a new animal called Mouse. Mice can move around, get older, reproduce, and die. They can start breeding at age 3, live up to 25 steps, and have like a 15% chance of breeding. They can have up to 5 babies at once.

I assumed that mice do not eat other animals and that foxes do not hunt mice. Mice can die from old age or if there is no room to move. I also updated the Simulator class so mice appear in green and have like a 6% chance of being created.

I compiled the classes and tested the simulation. Everything compiled and the simulation ran well with all three animals.
